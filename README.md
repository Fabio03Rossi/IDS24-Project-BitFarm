# IDS24-Project-BitFarm

Branch principale **final**:
- File Visual Paradigm contenente i modelli di tutte le iterazioni: *BitFarm.vpp*;
- File di codice relativi all'applicativo in: *src*.


## Iterazione 1
Nella prima iterazione è stata effettuata un'approfondita analisi della richiesta, svolgendo una prima analisi dei requisiti.
Sono stati identificati i primi casi d'uso, compresi di attori ed alcuni flussi di esecuzione rappresentativi.
Successivamente è stato redatta anche una prima bozza del diagramma delle classi di analisi, per cercare di comprendere
meglio la realtà di rappresentazione.


## Iterazione 2
Nella seconda iterazione è stato rivisitato il diagramma dei casi d'uso, approfondendo alcune rappresentazioni e aggiungendo casistiche non ancora affrontate.
Questo è stato possibile grazie ad alcune situazioni affrontate nel precedente diagramma di classi di analisi, ulteriormente approfondito in questa fase.
Inoltre sono stati redatti una prima bozza, ed un'ulteriore versione del diagramma delle classi di progetto applicando alcuni dei design pattern ritenuti rilevanti per il dominio di applicazione.
Infine l'aggiunta dei principali diagrammi di sequenza ha permesso una miglior comprensione della struttura comunicativa, delineando alcuni cambiamenti per la prossima iterazione e la scrittura di una parte del codice.

## Iterazione 3
Nella terza iterazione, sono stati svolti e ridefiniti tutti i modelli già descritti per correggere problematiche, completando i diagrammi di sequenza ed il codice Java, portandolo anche su SpringBoot.
Si è analizzato ulteriormente il flusso di sviluppo per confermare la corretta funzionalità e chiarezza, individuando però delle importanti mancanze che hanno portato all'esecuzione di ulteriori iterazioni.
Inoltre sono state riscontrate molte criticità all'interno del codice.
